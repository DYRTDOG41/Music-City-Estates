What this test does

The host creates a room code. Rapper B joins from a second phone. Fans can join the same code as audience members. Rapper audio is sent peer-to-peer, while the battle beat is generated on each device and started from a shared timestamp. Headphones are strongly recommended for both rappers to prevent echo.

MVP networking uses WebRTC through PeerJS public signaling so it can run from GitHub Pages without your own game server. That is good for testing. Before a public launch, Music City Estates should move signaling, moderation, identity, room persistence, and abuse controls to production infrastructure.
